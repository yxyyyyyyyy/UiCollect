# UiCollect

我的前端作品集。这里收录可直接打开的界面、动效、数据可视化和 3D 页面。

在线浏览：[uicollect.yxyyy.top](https://uicollect.yxyyy.top/)

本仓库只包含公开的静态前端文件：作品集入口在 `UI审美积累/index.html`，单页作品分别放在 `UI审美积累/pages/`、`单html文件/`、`notes/` 和 `3D卡片人物展示效果/`。`UI审美积累/assets/js/portfolio-data.js` 是公开的作品目录数据。

本地预览可在仓库根目录运行 `python3 -m http.server 8000`，然后打开 `http://localhost:8000/`。部分 3D 与交互作品依赖 CDN，离线时可能无法完整运行。
